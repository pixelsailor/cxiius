# Acceptance criteria

- [ ] `getSkillRecords()` returns a flat, typed list with `categoryId` and `stackIds` on every skill.
- [ ] System prompt lists skills with category and stack tags for AI consumption.
- [ ] Resume page offers Category / Proficiency / Tech stack grouping without duplicate skills in category mode.
- [ ] View mode persists in localStorage when JS is available; category mode works without JS.
- [ ] `npm run check` and skills presentation unit tests pass.
